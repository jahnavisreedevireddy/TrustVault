# TrustVault Security Threats

1. Unauthorized document access.
2. Weak user passwords.
3. Unauthorized permission changes.
4. Malicious file uploads.
5. Unauthorized document downloads.
6. Audit log modification.
7. Session hijacking.

# Security Measures

1. Password hashing.
2. Login authentication.
3. Role-based access checks.
4. CSRF protection.
5. File size restrictions.
6. Random stored filenames.
7. SHA-256 document hashes.
8. Permission verification.
